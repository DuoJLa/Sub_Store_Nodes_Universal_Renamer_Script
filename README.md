# Sub-Store 节点通用处理脚本

一个用于 [Sub-Store](https://github.com/sub-store-org/Sub-Store) 的节点重命名操作脚本，支持对订阅节点进行**自动过滤、地区识别、重命名标准化和多级排序**，适用于代理订阅的日常管理与美化。
初衷：我就是懒得逐个去改命名，遂搞个通用的直接一步搞定

---

</div>

## 功能特点

| 功能 | 说明 |
|------|------|
| 🚫 节点过滤 | 自动过滤订阅通知、广告、到期提醒等非正常节点 |
| 🌍 地区识别 | 支持 ISO 代码映射、名称明文匹配、中文字符模糊提取三级兜底 |
| ✏️ 输出格式 | 统一输出格式：`[旗帜] [地区] [类型] [序号] [倍率]` |
| 🔢 序号提取 | 分步正则提取数字/字母序号，避免倍率数字误识别，支持复杂命名格式 |
| 📊 多级排序 | 五级复合排序：地区权重 → 节点类型 → 序号分类 → 序号值 → 原始名兜底 |
| 🏳️ 旗帜处理 | 自动获取国旗 emoji，并对敏感旗帜进行替换！ |

## 节点重命名格式

脚本将所有节点重命名为统一格式，便于识别和管理：

```
[旗帜] [地区名] [节点类型(可选)] [序号(可选)] [倍率(可选)]
```

**示例：**

| 原始名称 | 重命名结果 |
|---------|-----------|
| `HK-专线-01-2x` | `🏳️ 香港 专线 01 2x` |
| `Japan High Speed A` | `🏳️ 日本 高速 A` |
| `新加坡节点 03` | `🏳️ 狮城 03` |
| `US 1x Standard` | `🏳️ 美国 01` |

> **注意**：倍率为 `1x` 时不显示，避免命名冗余。

## 排序规则

排序按以下五个优先级依次进行：

1. **地区权重**（地区优先级 → 小众地区按大洲兜底）
2. **节点类型**（专线 > 高速 > 家宽 > 直连 > 其他）
3. **序号分类**（数字序号 > 字母序号 > 无序号）
4. **序号值**（数字按数值升序，字母按字典序）
5. **原始名称**（以上均相同时，按原始名称字典序兜底）

### 地区排序优先级

**高优先级地区（按序）：**

香港 → 台湾 → 澳门 → 日本 → 狮城（新加坡）→ 美国 → 韩国 → 泰国 → 马来西亚 → 菲律宾 → 越南 → 印尼

**其余地区按大洲分组排列：**

亚洲其他 → 欧洲 → 美洲 → 非洲 → 大洋洲 → 未知地区

## 使用方法

### 1. 安装 Sub-Store

参考 [Sub-Store 官方文档](https://github.com/sub-store-org/Sub-Store) 完成安装与配置。

### 2. 添加脚本

1. 打开Sub-Store订阅面板
2. 进入对应订阅的脚本操作配置
3. 选择本地脚本
4. 将本仓库中的脚本代码完整粘贴至编辑框
5. 保存并刷新订阅

### 3. 验证效果

刷新订阅后，节点列表应呈现统一格式的命名与排序结果。

## 过滤关键词说明

脚本会自动过滤节点名称中包含以下关键词的条目：

```
群、邀请、返利、循环、官网、客服、网站、网址、获取、订阅、流量、到期、机场、下次、版本、官址、备用、过期、已用、联系、邮箱、工单、贩卖、通知、
倒卖、防止、国内、地址、频道、无法、说明、使用、提示、特别、访问、支持、教程、关注、更新、作者、加入、超时、收藏、福利、好友、失联
```

> ⚠️ **注意**：若发现正常节点被误过滤，请优先检查节点名称是否包含上述关键词（如"更新"、"支持"等）。可根据实际订阅情况调整脚本中的关键词列表。
